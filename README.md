# Agência Bancária em JavaScript

Projeto de agência bancária escolar desenvolvido com HTML, CSS e JavaScript.

## Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta no Visual Studio Code.
3. Abra `index.html` no navegador (ou utilize a extensão Live Server).

Arquivos principais: `index.html`, `style.css` e `script.js`.
